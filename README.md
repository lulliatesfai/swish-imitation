
# Swish-Inspired Payment Application

This project is a backend-based payment system inspired by Swish, built using Java and MySQL.

## Features
- Simulates real-time transactions
- Handles user accounts and payments
- Uses a relational database for data storage
- Focus on data consistency and reliability

## Technologies
- Java
- MySQL

## Description
The project focuses on backend logic, transaction handling, and database design, simulating a simplified financial payment system.
